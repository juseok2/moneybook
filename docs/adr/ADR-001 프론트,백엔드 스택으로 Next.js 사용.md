# ADR-001: 프론트/백엔드 스택으로 Next.js 사용

## 상태

승인됨 (2026-07-21)

## 상황 (Context)

해당 프로젝트의 주 목적은 앱 개발이 아니라 개발 프로세스 학습,회사 스택이 Next.js인데 본인은 ai로만 개발했지 손으로 직접 코딩하지않아 해당 스택에 대한 경험 부족,실제 경험은 스프링

## 결정 (Decision)

Next.js를 사용하기로 결정

## 근거 (Rationale)

회사 스택이니 ai가 짠 코드를 제대로 검토 할 수 있는 능력으로 환전됨

## 대안과 기각 사유 (Alternatives)

대안은 스프링 사용
기각 사유 익숙한 스택이라 빠르게 결과물이 나올 수 있겠지만 해당 프로젝트의 취지에 적합하지 않음

## 결과 (Consequences)

본 프로젝트의 목적이 상실되니 개발은 내가 직접하고 ai는 검토만 하기로 결정
새로운 기술스택을 사용하기에 개발 시간이 오래 소요될 수 있음
