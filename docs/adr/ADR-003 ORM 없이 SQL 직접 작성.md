# ADR-003: ORM 없이 SQL 직접 작성

## 상태

승인됨 (2026-07-22)

## 상황 (Context)

본 프로젝트 구축을 할 때 ORM 사용과 SQL 직접작성중 고민하는 상황,본 프로젝트의 목적은 기본기를 손으로 익히는 것이며 회사는 SQL 직접작성 방식 사용

## 결정 (Decision)

SQL 직접작성으로 결정,마이그레이션도 도구없이 번호를 붙인 파일로 관리한다

## 근거 (Rationale)

ORM은 SQL을 감춰서 어떻게 돌아가는것인지 명확하게 알 수가 없음 이것은 AI가 짜는것과 같은 효과를 냄 그래서 SQL이 직접 노출되는 방식을 채택함
회사의 방식과 동일하다 그래서 본 프로젝트에서 작성한 SQL문들이 실무와 직결된다

## 대안과 기각 사유 (Alternatives)

대안 ORM
기각사유 개발속도가 빠르고 타입 안전성이 제공되며 마이그레이션도 자동화 된다 하지만 이 장점들이 SQL을 안봐도 되는데서 나오므로 본 프로젝트의 목적이 상실된다

## 결과 (Consequences)

개발기간 증가,ORM이 해주던 일을 본인이 직접 해야한다. SQL인젝션 방어 - (파라미터 바인딩 강제, 문자열 조립 금지),타입 안전성 없음,마이그레이션 수동 관리 필요
